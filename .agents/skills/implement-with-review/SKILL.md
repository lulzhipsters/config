Implement the work described by the user in the spec, ticket or tasks.

Work through each task, stage or phase one by one, committing each separately.
Before each commit, run the /format skill.
Run checks on each commit and seek review from a subagent.
Consider subagent feedback, but raise anything to the user that may overcomplicate the implementation.

Ask the user for review and integrate any changes into the relevant commit before proceeding to the next.
